Menu box review

Click a box to select. Drag inside to move; drag a corner to resize. Drag the round handle above the box to rotate. Use “Draw new box” to draw over existing boxes.

1 / 2 / 3: class
Z / C: rotate −1° / +1°
X / V: rotate −0.1° / +0.1°
Delete / Backspace: remove
Space / Enter: save verified & next
Ctrl+Z: undo

All predictions require human review, including images with no boxes. Prices and orientation are heuristic suggestions. Review interior signage too.
